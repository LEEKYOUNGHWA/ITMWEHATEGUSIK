# 화면 스타일 관리

모든 화면의 CSS 원본을 이 폴더에서 관리합니다.

- `index.css`: 전역 CSS의 유일한 진입점입니다. `src/main.js`가 불러오며, 기존 테마와 공통 스타일의 적용 순서를 유지합니다.
- `common/`: 두 테마가 공유하는 기본 요소와 헤더 배치입니다.
- `themes/retro/`: 레트로 기본 화면, 사용자·가게·환경설정 화면, 돌림판·지도 배치와 디자인 설정입니다.
- `themes/classic/`: 클래식 디자인과 현재 화면 컨트롤입니다.
- `components/`: 프로필 메뉴, 참여자 커서, 결과 공유, 화면 효과, 공용 기록·채팅, 돌림판 등 양쪽 테마에서 함께 사용하는 컴포넌트 스타일입니다.
- `pages/`: 트리방 등 개별 페이지 스타일입니다.

Vue 컴포넌트는 `<style scoped src="…">`로 이 폴더의 CSS를 연결합니다. `scoped`와 `:deep()`는 Vue가 처리하므로 이 파일들을 전역 진입점에도 중복 등록하지 않습니다. 트리방 CSS는 `ChristmasPage.vue`에서 연결해 페이지와 함께 지연 로딩합니다.

테마 전용 파일의 `@scope`와 `index.css`의 순서를 유지하세요. 공통 변경은 `common/` 또는 해당 공유 컴포넌트 파일에서 한 번만 수정하고, 테마 고유 색상·장식·배치는 각 테마 파일에서 관리합니다. 새 스타일을 Vue 안이나 별도 폴더에 추가하지 않습니다.

돌림판 버튼의 위쪽 이동량은 `components/wheel-panel.css`의 `--button-lift`에서 조정합니다. 가게별 결과 검색 링크도 같은 파일에서 관리합니다.

모바일(760px 이하)의 화면 폭, 패널 크기, 양쪽 가운데 회색 화살표는 `common/responsive.css`에서 관리합니다. 화살표에는 글자를 표시하지 않고 접근성 이름으로 용도를 안내합니다. 모바일은 돌림판과 기록·대화방 중 하나만 열 수 있고 둘 다 접을 수도 있습니다. 추첨이 끝나면 돌림판을 접어 지도를 보여주며, 다시 열어 결과와 네이버 검색 링크를 확인할 수 있습니다. 패널 상태와 화면 크기 변경은 `src/composables/useWorkspaceLayout.js`에서 처리합니다.

모바일 패널은 각각 왼쪽·오른쪽 화면 끝에 붙은 서랍입니다. `App.vue`의 `wheel-drawer`·`records-drawer` 전환으로 열고 닫으며, 흰 배경의 화살표 버튼도 같은 시간과 곡선으로 패널 바깥 가장자리를 따라 움직입니다. 둘 다 접혀 있으면 두 열기 버튼을 표시하고, 하나를 펼치면 해당 서랍의 접기 버튼만 표시합니다. 애니메이션 시간은 `--drawer-duration`, 곡선은 `--drawer-easing`, 너비는 `--mobile-drawer-width`에서 관리합니다. 모션 줄이기 설정에서는 애니메이션을 생략합니다.

사용자 위치, 룰렛 크기, 색상 선택처럼 실행 중 바뀌는 값은 Vue의 동적 스타일 바인딩으로 유지합니다. Leaflet의 CSS는 외부 라이브러리에서 제공하며, Canvas·Three.js 그리기는 CSS가 아닌 각 렌더러에서 관리합니다.
