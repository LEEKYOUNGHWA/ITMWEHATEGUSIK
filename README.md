# GS강서타워 점심 돌림판

Vue 3 + Vite + Node.js + WebSocket으로 만든 사내 공유 점심방입니다. 4명 정도가 같은 주소로 접속해 돌림판, 식당 선택, 선정 이력, 커서, 채팅을 함께 봅니다.

## 실행 / 종료

이 PC에는 기존 Node 실행 파일을 재사용한 로컬 실행 환경을 `C:\Users\rudgh\AppData\Local\lunch-node\bin`에 준비했습니다. 사용자 PATH도 등록했습니다. **새 PowerShell/터미널에서** 실행하세요. 기존 VS Code 터미널에서 명령이 안 잡히면 VS Code까지 다시 열거나 아래 PATH 설정을 한 번 실행하세요.

```powershell
$env:Path = "$env:LOCALAPPDATA\lunch-node\bin;$env:Path"
cd "C:\Users\rudgh\Documents\GS강서타워 점심 돌림판"
npm run dev
```

평소에는 폴더에서 `npm run dev`만 실행하면 됩니다. Vue 화면과 공유 서버가 함께 켜지고 코드 수정도 바로 반영됩니다. 종료는 **실행한 터미널에서 Ctrl+C**입니다. 별도의 백그라운드 서비스나 부팅 자동 실행은 등록하지 않았습니다. 이 창을 닫거나 PC를 끄면 다른 사람도 접속할 수 없습니다.

다른 PC로 프로젝트를 복사할 때에는 Node 22.12 이상(권장: 24)을 설치하고 최초 한 번 아래 명령을 실행합니다.

```powershell
npm install
npm run dev
```

화면을 빌드해서 서비스하려면:

```powershell
npm run build
npm start
```

개발 실행과 빌드 실행은 같은 3000번 포트를 쓰므로 동시에 실행하지 마세요. 현재 어느 쪽이 켜졌는지는 해당 터미널의 실행 명령으로 확인할 수 있습니다. 브라우저 http://localhost:3000/api/health 에서 서버 응답 여부도 확인할 수 있습니다.

## 다른 사람 접속

시작할 때 `사내 접속: http://내부IP:3000` 주소가 표시됩니다. 같은 사내망에 있는 동료에게 이 주소를 알려주세요. 구현 당시 주소는 `http://10.53.85.158:3000`이며 Wi-Fi/DHCP/VPN 변경 시 달라질 수 있습니다.

- 본인 PC: http://localhost:3000
- 동료 PC: 시작 로그에 표시되는 사내 접속 주소
- 상태 확인: http://localhost:3000/api/health
- Node 서버가 0.0.0.0:3000으로 수신하므로 사내 IP로 접속할 수 있습니다. 기존에 접속 가능한 환경의 방화벽은 변경하지 않습니다.
- 회사의 무선 단말 간 통신 차단/VLAN 정책은 Windows 방화벽과 별개입니다. 호스트에서 내부 IP 접속이 되는데 다른 PC에서 안 되면 사내 네트워크 정책을 확인하세요.
- 공유기 외부 포트포워딩은 설정하지 않습니다. 로그인 없이 사내망에서 사용하는 작은 앱입니다.

포트 변경은 실행할 터미널에서 설정합니다.

```powershell
$env:PORT = "3100"
npm run dev

```

## 식당 / 좌표 관리

**`config/restaurants.json`만 수정하면 됩니다.** UTF-8 JSON 배열이고, 파일 저장 후 서버를 Ctrl+C로 종료하고 `npm run dev`로 다시 켜면 반영됩니다. 브라우저는 재접속하며 최신 식당 정보를 받습니다.

```json
{
  "id": "r13",
  "name": "새 식당",
  "category": "한식",
  "description": "대표 메뉴를 적어주세요",
  "hours": "도보 약 5분 · 11:00–21:00",
  "address": "서울특별시 영등포구 ...",
  "lat": 37.520814,
  "lng": 126.889040,
  "source": "좌표를 확인한 페이지 주소 (선택)",
  "coordinateNote": "위치 관련 메모 (선택)"
}
```

- Google 지도에서 가게 위치를 우클릭하면 **위도, 경도**가 표시됩니다. 첫 숫자를 `lat`, 두 번째를 `lng`에 따옴표 없이 입력하세요.
- 위치를 모르겠으면 `"lat": null, "lng": null`로 둡니다. 돌림판에는 나오고 지도 핀·이동만 생략됩니다.
- `id`는 식당마다 고유하게 정하고 기존 식당의 ID를 다른 식당에 재사용하지 마세요.
- 이름/메뉴/시간/주소도 자유롭게 수정할 수 있습니다. 식당을 추가할 때는 배열 안에 객체를 하나 더 넣으세요. 식당 사이 쉼표가 필요하고 마지막 객체 뒤에는 쉼표를 붙이지 않습니다.
- 신규 식당은 다음 서버 시작 때 목록에 나타납니다. 기존 체크 상태는 유지되며, 추가한 식당은 화면에서 체크해 주세요.
- 삭제된 식당의 과거 선정 이력은 당시 이름과 정보로 남습니다.
- 잘못된 JSON, 중복 ID, 잘못된 좌표는 시작할 때 식당 이름/파일명과 함께 오류를 표시합니다.

현재 12곳 중 10곳에 주소를 대조한 좌표를 넣었습니다. 건물 대표 좌표가 포함되어 실제 가게 출입구와 차이가 있을 수 있습니다. 각 항목의 `source`, `addressSource`, `coordinateNote`에서 근거를 확인할 수 있습니다. 소문난식당은 주소만 입력했고, 서여산은 원본 이름으로 지점을 확인하지 못해 좌표를 비웠습니다. 원본의 거리와 영업시간은 갱신하지 않았으니 직접 확인해 주세요.

배경의 GS강서타워는 선유로 75 건물 대표 위치를 사용합니다. 출처: https://rlh.purpleo.kr/article/5101

## 화면

- 중앙: 돌림판, 선정 결과, 공유 식당 체크 목록
- 우측: 선정 이력 / 채팅 탭, 접속자 목록
- 하단: 내 이름, 사람 이모지, 채팅 입력 (Enter로 전송)
- 좁은 화면: 상단의 `이력 · 채팅` 버튼으로 우측 패널 열기/닫기
- 상단 ◐ 버튼: 시스템 / 다크 / 라이트 테마 순환
- 커서: 중앙 공유 영역에서 이름·이모지와 함께 움직입니다. 최근 채팅은 커서 옆에 8초간 표시됩니다. 패널에서도 기록을 읽을 수 있습니다.
- 지도: OpenStreetMap + Leaflet 사용. 회전 시작 시 전체 범위로 복귀하고, 당첨되면 해당 식당으로 이동·확대합니다. 외부 지도 접속이 막히면 크림색 배경에서 돌림판은 계속 작동합니다. Google API 키가 필요하지 않습니다.

지도 출처 표시는 유지해야 합니다. OSM 타일은 일반 브라우저 캐시 정책을 따르며 미리 다운로드하지 않습니다. https://operations.osmfoundation.org/policies/tiles/

## 데이터 보관

서버가 만드는 `data` 폴더:

- `settings.json`: 식당 체크 상태, 마지막 회전 각도, 진행 중 회전
- `history.jsonl`: 선정 이력 (한 줄에 JSON 한 건)
- `chat.jsonl`: 채팅 내역 (한 줄에 JSON 한 건)
- `profiles.json`: 접속 IP별 이름·이모지·수정 시각

파일에 계속 기록하며 화면에서는 이력 최근 500건과 채팅 최근 200건을 보여줍니다. SQLite/외부 DB는 사용하지 않습니다. 이름·이모지는 접속 IP를 기준으로 서버의 profiles.json에 기억하며 각 브라우저의 localStorage에도 저장합니다. 같은 IP로 재접속하면 서버에 저장된 정보가 우선 적용됩니다. 하단에서 이름이나 이모지를 변경하면 저장되며 같은 IP의 열린 탭에도 반영됩니다. IP가 바뀌면 다른 항목으로 취급하고, 처음 보는 IP에는 브라우저에 기억된 이름·이모지를 가져옵니다. 여러 사람이 같은 IP를 공유하면 하나의 프로필을 사용합니다. 서버는 실제 소켓의 IP를 사용하고 X-Forwarded-For 같은 요청 헤더는 신뢰하지 않습니다. IP 정보는 화면이나 상태 API에 노출하지 않습니다. 커서 좌표와 온라인 상태는 저장하지 않습니다. 자료를 백업하려면 서버 종료 후 `config`와 `data` 폴더를 복사하세요.

서버가 회전 도중 꺼졌다면 재시작 때 저장된 회전 결과를 확정하고 이력에 한 번만 남깁니다. 저장 실패 시 화면에 알림이 표시되며 이력 저장이 복구될 때까지 다음 회전을 막습니다. 파일이 손상되면 시작 시 해당 파일과 줄 번호를 알려주며 임의로 기록을 삭제하지 않습니다.
